# CustomToolBar
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.6.1.

## Modules
`src/shared` ships **two** sibling toolbar modules (both build into
`ReplicatedStorage.Shared`). They share the same architecture but differ in look:

- **`CustomToolbar`** — general-purpose, native-mirroring drop-in. Classic flat
  slots with a vector `UIStroke` border and animated rarity outlines. No
  fake-stroke styling.
  ```lua
  local CustomToolbar = require(ReplicatedStorage.Shared.CustomToolbar)
  CustomToolbar.new():Mount()
  ```
- **`TheHostToolbar`** — game-specific build with the signature *fake textured
  stroke* look (image-based border) **ON by default**. Meant to be tailored to a
  single game without bloating the general-purpose `CustomToolbar`.
  ```lua
  local TheHostToolbar = require(ReplicatedStorage.Shared.TheHostToolbar)
  TheHostToolbar.new():Mount()
  ```

The demo client (`src/client/init.client.luau`) mounts **`TheHostToolbar`**.

> **Mount exactly one per client.** Both modules disable the native CoreGui
> Backpack and auto-manage tools from `player.Backpack` on `:Mount()`, so mounting
> both at once would produce overlapping toolbars. (Note: `:Destroy()` does not
> currently re-enable the native Backpack.)

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "CustomToolBar.rbxlx"
```

Next, open `CustomToolBar.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
